# The Gateway Files

A field guide to the declassified CIA **Gateway Process** record — the 1983 McDonnell
report, the 1977 Gateway Intermediate Workbook, evidence-graded frequency research, and
an **interactive Frequency Lab** — as a single self-contained website plus a research
archive.

## Honesty statement

This is a study guide to historical documents and a graded review of adjacent science.
The 1983 report's claims (out-of-body travel, holographic-universe consciousness) are
presented as the record states them — not as validated science. Nothing here is medical
advice; the audio presets are study artifacts, not treatments.
